# Historical backlink preservation and verification

Only Pages 886, 674, 413 and 1043 required a change: one HTML href per page, from `https://rmhughes.edublogs.org/classroom-explorations/` to canonical `https://rmhughes.edublogs.org/hub/`. The labels and every other source byte were retained. CSS and JavaScript editor fields were not edited. Mushrooms has two Custom HTML blocks: only the first (separate backlink) was changed; the second (complete lesson) was captured and proved byte-identical after saving.

`before` files are exact authenticated-editor preservation captures. `saved` files were captured after Save and editor reload. `expected-HTML` is the one-substitution derivative, not a new lesson manifest. Restore the affected block from all three `before` fields if necessary; do not replace the complete Mushrooms page with its small backlink block. All WordPress IDs, parents, slugs, templates, titles and unrelated blocks were retained.

`verification.json` is generated by `tools/verify-classroom-explorations-historical-backlinks.mjs`. It verifies the four source deltas and public return destinations, and also checks all nine managed exploration/learning child pages for a canonical global menu and absence of the retired href. Other child pages were not edited. These legacy field captures do not mean their contents have been standardized as Lanternworks-editable source manifests; that adoption remains separate work.
